# incident.io Sandbox

We have an [incident.io sandbox instance](https://app.incident.io/gitlab-sandbox-v2/dashboard) that can be used to test features without affecting our main [incident.io instance](https://app.incident.io/gitlab/dashboard)

## How to get access

1. You would require access to Slack Sandbox workspace `gitlab-sandbox-v2` to be able to authenticate yourself to
the incident.io sandbox instance, create an AR like [this](https://gitlab.com/gitlab-com/team-member-epics/access-requests/-/work_items/44891) to request access.

2. Visit [incident.io dashboard](https://app.incident.io/gitlab/dashboard) and select `Switch account` from the top left menu, Click add organization

3. Authenticate into incident.io sandbox account via `gitlab-sandbox-v2` as the Slack workspace option.
