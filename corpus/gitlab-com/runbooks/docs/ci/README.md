# CI (Pipeline Authoring) Runbooks

Runbooks for CI/CD pipeline configuration and creation features owned by the
Verify:Pipeline Authoring group.

## Contact Information

- **Group**: Verify:Pipeline Authoring
- **Handbook**: [Pipeline Authoring](https://handbook.gitlab.com/handbook/engineering/devops/verify/pipeline-authoring/)
- **Slack**: [#g_pipeline-authoring](https://gitlab.enterprise.slack.com/archives/C019R5JD44E)

## Runbooks

- [Pipeline Creation](pipeline-creation.md): no pipelines being created, config fetch
  timeouts, pipelines created with errors
- [CI/CD Variables Troubleshooting](ci_variables_troubleshooting.md): missing/empty
  variables, precedence, masking
- [CI Protected Variables](protected-variables.md): protected variables not available
  or exposed unexpectedly
- [CI Inputs](inputs.md): `spec:inputs` validation errors

For runner-related issues, see [CI Runners](../ci-runners/README.md).
