# POSTHOC statement-class references

Broad P, broad O, and whole-word case-insensitive `files?`, `users?`, and `tests?`
are counted once per primary ordinary-prose sentence/list-item unit.
The global finite-slot reference preserves total matches and statement capacities;
the conditioned reference also preserves each publisher's total.

From the artifact root:

```text
python code/posthoc_topic_words.py
```

Output: `reproduced/POSTHOC-topic-words/`. It contains the class table, per-document
counts, fixed seeds, and all 499 draws for each reference and class.
The stored files here contain the corresponding table, counts, and draws.
